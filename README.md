# Simple-Kiosk-Ordering-System-Java
A Java console program simulating a food kiosk ordering system with receipt generation

##Overview
This is a simple kiosk ordering system where a customer can choose between Fries, Pizza, or a Burger, pick their size/flavor, enter the quantity, and get a computed total with a printed receipt.
##Background
I made this project during the break after my 1st year, 1st semester as a BSIS student. I was learning Java, our new programming language for the upcoming 2nd semester.
While I was learning the syntax for selection structures, repetition structures, and basic functions and declarations, I suddenly thought of the idea of how a kiosk works. So I started turning that idea into reality.
##How I Built It
Every line of code came from my own idea — the menu flow, the pricing, the receipt format. Since it's built on my own design rather than following a tutorial, some parts (like variable names) got repeated a lot across sections and aren't very descriptive.
That's really all I set out to build — a simple, working kiosk ordering system.
##Files
project_kiosk1.java — contains the core logic and methods (menu, fries, pizza, burger ordering, pricing, and receipt printing)
project_kiosk2.java — the entry point that handles the main menu selection and calls the methods above
## Tools used
Java, IntelliJ IDEA (no external libraries)
