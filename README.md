# Simple-Kiosk-Ordering-System-Java
A Java console program simulating a food kiosk ordering system with receipt generation

This is a simple kiosk that I made after my 1st Year first Semester break as a BSIS student. I do this project while I'm learning our new programming language (Java) for our upcoming 2nd Semester. 

While I'm learning the syntax for selection structure and repetition structure and basic function and declaration, I suddenly thought with the idea of how kiosk work. Then I started making my idea into reality.

Every single line of code made from my idea, also the variables that I made is more likely repeated and not so formal.

All I want to do is to make a simple kiosk ordering system.
